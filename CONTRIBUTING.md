# VISIO team development workflow

1. Accept Binupa's GitHub invitation and clone the repository.
2. Work in a feature branch, not directly on main.
3. Keep commits small, with messages like feat: add camera connection UI
   or fix: improve team cards on mobile.
4. Run npm run build before pushing.
5. Open a pull request; add a summary, screenshots for UI work, and test notes.
6. Ask a teammate to review, address feedback, and merge when approved.
7. Run git pull origin main to sync approved changes.

Do not push credentials, personal data, real camera footage, or VPS deployment files.
Coordinate any deployment of the live site with the team first.
