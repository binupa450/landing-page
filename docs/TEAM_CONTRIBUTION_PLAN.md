## Evidence, not artificial GitHub percentages

- GitHub commit counts, lines of code, PRs, code reviews and issues help
  document work, but they are **not** an authoritative measure of effort.
- GitHub's Contributors page derives its metrics from actual commit history.
  Do not change commit authors, create filler commits, or attribute other
  members' work to influence a displayed percentage.
- Keep genuine dated evidence: issues, reviewed PRs, test reports and
  meeting notes.
- University/academic contribution declarations must reflect actual
  work and be approved under the module's assessment rules.
